# 智驾通

#### 介绍
面向驾考备考人群，研发一个集智能刷题、错题诊断、个性化出题、法规问答、交通标志识别与知识可视化于一体的 AI 驾考学习平台。项目以大模型为核心，结合 RAG 检索增强、知识图谱和多模态识别技术，为用户提供更高效、更个性化、更具交互性的驾考学习与道路安全知识服务。
